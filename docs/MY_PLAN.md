# Campus Quest – My Project Plan

## 1. Festival Theme

**A World of Traditions: Celebrating Cultures Across the Globe**

Our school festival will celebrate traditions from different countries around the world. Visitors will discover cultural celebrations, music, dances, clothing, food and customs. The aim is to help people appreciate the diversity of cultures.

## 2. Visitor Needs

1. I want to discover traditional celebrations from different countries.
2. I want to find cultural performances quickly.
3. I want to save interesting cultural activities to my personal schedule.

## 3. Ten-Session Coding Plan

1. **Day 1:** Set up the project, explore the starter code and plan the website.
2. **Day 2:** Add festival events and semantic HTML sections.
3. **Day 3:** Improve the website's layout using responsive CSS.
4. **Day 4:** Build JavaScript search and category filters.
5. **Day 5:** Create My Schedule and the quest points system.
6. **Day 6:** Use localStorage to save events between visits.
7. **Day 7:** Build a form for proposing new events, with validation.
8. **Day 8:** Improve accessibility and test for bugs.
9. **Day 9:** Review the project, make revisions and synchronise changes.
10. **Day 10:** Polish the website and prepare the portfolio and demonstration.

## 4. How the Project Files Connect

- **index.html:** Contains the structure and sections of the website.
- **styles.css:** Controls the appearance and layout of the website.
- **js/events.js:** Stores the festival event information in JavaScript objects.
- **js/app.js:** Uses the event information to display events and handle interactions such as searching, filtering and saving.

The HTML provides the structure, CSS makes it look good, and JavaScript makes it interactive. The JavaScript files work together: events.js provides the data, while app.js uses that data to build and update the page.
